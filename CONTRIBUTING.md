# Contributing to the synthetic demo

This is an original portfolio application. Keep all examples fictional, all seed data reproducible and the ProductMaster / ProductIntelligence boundary explicit. Never add real ERP extracts, proprietary category files, corporate screenshots, client/supplier records, personal data, credentials or internal documents.

Run `python -m pytest -q` before a pull request. Changes to taxonomy completeness or attribute applicability must include a regression test and an acceptance explanation. Changes to metric calculations must specify period, unit, quality state and analytical ownership.
